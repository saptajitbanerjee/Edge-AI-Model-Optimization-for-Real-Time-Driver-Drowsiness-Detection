# Edge-AI-Model-Optimization-for-Real-Time-Driver-Drowsiness-Detection
Model compression pipeline (TFMOT + ONNX hybrid) for real-time driver drowsiness detection — benchmarked across 5 CNN architectures (MobileNetV3, ResNet-18, RTDD) for edge/FPGA deployment. Includes CARLA closed-loop safety intervention system. DL/Edge-AI component of a hardware-software co-design project (IIT Madras, CS6651).
